# SRJ — نسخه آزمایشی (اپ پرسنل + داشبورد مدیریت + ویجت)

## فایل‌ها
- SRJ_Personnel_App.html — اپ پرسنل (نصب‌پذیر PWA)
- SRJ_Management_Dashboard.html — داشبورد مدیریت
- SRJ_Widget.html — صفحه فشرده وضعیت + میان‌بر ورود/خروج
- manifest.json / sw.js / icons — نصب روی گوشی

## راه‌اندازی (بار اول)
1. هر ۳ فایل HTML + manifest.json + sw.js + پوشه icons را کنار هم در یک مخزن با GitHub Pages آپلود کنید
   (پیشنهاد: مخزن جدا و عمومی فقط برای «نمایش اپ»؛ مخزن «داده» همچنان خصوصی بماند).
2. آدرس: https://OWNER.github.io/REPO/SRJ_Personnel_App.html
3. روی هر گوشی: باز کردن آدرس → اطلاعات اتصال (owner/repo داده/branch/path/token) → ورود → «Add to Home screen».
4. مدیریت: آدرس SRJ_Management_Dashboard.html → همان اطلاعات اتصال → ورود admin / admin123 → رمز را عوض کنید.

## نکات مهم
- نام کاربری پرسنل باید انگلیسی و بدون فاصله باشد؛ حروف بزرگ/کوچک و رمز فارسی‌نویس خودکار یکسان می‌شود.
- لغو ورود/خروج تا قبل از تایید مدیر ممکن است؛ همه لغوها در «تنظیمات سیستم ← گزارش تغییرات» ثبت می‌شود.
- بدون اینترنت: ثبت‌ها در صف گوشی می‌مانند و با اتصال خودکار ارسال می‌شوند.
- سربرگ (نام شرکت، آدرس، تلفن...) از «تنظیمات سیستم» ویرایش می‌شود و روی فیش، نامه، PDF و اکسل می‌آید.
- ویجت واقعی صفحه اصلی گوشی فقط با اپ نیتیو ممکن است؛ این بسته «SRJ_Widget.html» و میان‌برهای نگه‌داشتن آیکون (اندروید) را دارد.
