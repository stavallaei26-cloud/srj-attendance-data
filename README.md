# SRJ - راهنمای هماهنگ‌سازی و نصب اپ پرسنل

## چه چیزی عوض شد؟
اپ پرسنل (`SRJ_Personnel_App.html`) دیگر از حافظه محلی گوشی (localStorage) به‌تنهایی استفاده نمی‌کند.
حالا دقیقاً مثل داشبورد مدیریت، به **همان فایل JSON روی گیت‌هاب** وصل می‌شود (از طریق GitHub Contents API)،
پس هر ثبت تردد/اضافه‌کار/مرخصی توسط پرسنل، بلافاصله در داشبورد مدیریت قابل مشاهده و تایید است،
و برعکس، تاییدهای مدیریت با یک بروزرسانی خودکار (هر ۲۰ ثانیه) در اپ پرسنل ظاهر می‌شود.

## فایل‌ها
- `SRJ_Personnel_App.html` — خودِ اپ پرسنل (بروزشده)
- `SRJ_Widget.html` — صفحه فشرده وضعیت و KPI زنده (نزدیک‌ترین معادل «ویجت»، توضیح در پایین)
- `manifest.json` — فایل نصب PWA (Add to Home Screen)
- `sw.js` — سرویس‌ورکر برای نصب‌پذیری و بارگذاری سریع‌تر
- `icons/icon-192.png`, `icons/icon-512.png` — آیکون اپ
- `SRJ_Management_Dashboard.html` — داشبورد مدیریت (فقط سربرگ خروجی اکسل آن بروزرسانی شد)

## نحوه راه‌اندازی (روی همان مخزن گیت‌هاب فعلی)
1. همه فایل‌های بالا (به‌جز خودِ داشبورد مدیریت که از قبل دارید) را در **همان مخزن گیت‌هابی** که داشبورد مدیریت
   در آن راه‌اندازی شده قرار دهید (مثلاً کنار `index.html` داشبورد، یا در پوشه‌ای مثل `/personnel/`).
2. اگر GitHub Pages از قبل روی آن مخزن فعال است، آدرس اپ پرسنل چیزی مثل این می‌شود:
   `https://<owner>.github.io/<repo>/SRJ_Personnel_App.html`
3. اولین بار که پرسنل اپ را باز می‌کند، صفحه «اتصال به فضای ذخیره‌سازی» را می‌بیند و باید
   **دقیقاً همان owner / repo / branch / مسیر فایل داده (data/db.json) / توکن** مخزن داشبورد مدیریت را وارد کند.
   (توصیه: یک توکن جداگانه با دسترسی محدود فقط به همان مخزن برای پرسنل بسازید، نه توکن ادمین.)
4. بعد از اتصال، با نام کاربری/رمز عبوری که در تب «مدیریت پرسنل» داشبورد ساخته‌اید وارد می‌شود.

## تست سریع (بدون گیت‌هاب واقعی)
برای تست ساختار و ظاهر، کافی است فایل `SRJ_Personnel_App.html` را مستقیم در مرورگر باز کنید؛
صفحه تنظیمات اتصال نمایش داده می‌شود. برای تست کامل جریان داده، به یک مخزن گیت‌هاب واقعی (حتی خصوصی و آزمایشی) نیاز دارید،
چون مرورگر مستقیماً با GitHub API صحبت می‌کند.

## نصب روی گوشی (PWA)
- **اندروید (Chrome):** وارد آدرس اپ شوید → منوی سه‌نقطه → «Add to Home screen» / «نصب برنامه».
- **آیفون (Safari):** وارد آدرس شوید → دکمه Share → «Add to Home Screen».
پس از نصب، اپ مثل یک اپ نصبی مستقل (بدون نوار آدرس مرورگر) روی صفحه اصلی گوشی باز می‌شود.

## درباره «ویجت مخصوص خودش»
یک ویجت واقعی صفحه‌اصلی (مثل ویجت‌های اندروید/iOS که بدون باز کردن اپ روی خانه گوشی زنده بروزرسانی می‌شوند)
فقط با اپ نیتیو (Kotlin/Swift) ساخته می‌شود و از طریق HTML/PWA قابل ساخت نیست — این یک محدودیت پلتفرمی است، نه محدودیت این پیاده‌سازی.
نزدیک‌ترین معادل عملی که در این نسخه اضافه شده:
- **`SRJ_Widget.html`**: یک صفحه بسیار سبک که فقط وضعیت امروز و KPI زنده را نشان می‌دهد (بدون منو/تب) و می‌توان
  آن را جدا از اپ اصلی روی صفحه گوشی نصب/پین کرد.
- **Shortcuts در manifest.json**: با نگه‌داشتن (long-press) آیکون نصب‌شده اپ، دو میان‌بر «ثبت تردد سریع» و «ویجت KPI» ظاهر می‌شود.

## خروجی اکسل
سربرگ‌های هر دو خروجی اکسل (داشبورد مدیریت و اپ پرسنل) با پیشوند **«SRJ -»** بازنویسی شد.
در اپ پرسنل، تب «کارکرد ماهانه» یک دکمه «📊 دانلود اکسل کارکرد من (SRJ)» دارد که فایل اکسل شخصی
(شامل کارکرد روزانه، اضافه‌کار و وضعیت تایید) با نام `SRJ_کارکرد_<username>_<تاریخ>.xlsx` می‌سازد.
